Highlights

Every Platform

One Rust core powers every SDK, so a document renders the same PDF in JavaScript, Python, Java, C# and PHP, with no native extensions to build or install.

Your Data Stays Yours

The engine runs in-process, inside your infrastructure. No HTTP calls to an external service — documents are generated on the machine that hosts your application.

Declarative Document Model

Define documents in code, XML, or YAML. Flow layout handles structured content automatically; layers give exact coordinate control. Both coexist in the same document.

Data Binding

data-value, data-source, and data-if are first-class element attributes. Bind a JSON or XML file to a template — no external templating engine required.

Markdown

Set a body written in Markdown as a styled, paginated PDF, with tables, footnotes and a table of contents that fills itself. Covers, headers and footers stay in the XML.

Design Tokens

Spacing, typography, color, and borders are token-addressable at a single point. Swap the token file to restyle the entire document — white-labeling, themes, brand kits.

PDF Standards

PDF/A for archives, PDF/UA for accessibility, PDF/X for print and Factur-X for e-invoices, each one setting in the document.

VS Code Extension

Schema validation, live PDF preview on save, and code generation — built around the same XSD the engine validates against. Install from Marketplace or Open VSX.
